# 使用说明

浏览器运行真实 mGBA / WebAssembly 核心；同一个房间内的每位玩家控制一台独立的 GBA。支持 1 人练习及 2–4 人通信线联机。

## 立即使用

1. 在此目录双击「启动联机.cmd」，页面会自动打开。新建服务时保持命令窗口打开；重复双击会识别同一项目已运行的服务并直接打开网页。已附 Windows Node 运行时，无需安装 npm 或模拟器。
2. 本机打开 http://127.0.0.1:8765 。同一 Wi-Fi 的其他设备打开启动窗口中的 WLAN 局域网地址，例如本次环境为 http://10.17.0.55:8765 。IP 可能随网络变化，以启动输出为准。
3. 房主先选择游戏，再选择该游戏支持的人数、填写昵称并创建房间；其他人输入六位房间码。加入者会自动切换到房间的游戏，房间内不能改游戏。也可复制邀请链接。
4. 人数到齐后，房主点击「一起开始游戏」。每台设备都会读取本地服务器提供的 ROM 并校验 SHA-256。
5. 各自在游戏中按 Start 进入菜单，选择游戏的多人/通信模式，再按游戏内提示进入联机。**网页建房只连接 GBA 通信线，不会自动替你操作游戏菜单。**
6. 游戏期间所有玩家保持页面运行。退出、刷新、断网会停止整个小队；其他人仍保留房间，可以等待玩家重新加入后重新开机。

同一台电脑可以打开多个浏览器窗口进行测试，但要点选当前玩家的游戏画面再操作。触摸屏提供虚拟按键，标准布局手柄会自动识别。

## ROM切换与实际游戏模式

房间内的ROM固定。点击“退出房间并切换 ROM”会退出并停止当前对局，然后可以选择另一款游戏或另一个版本；原存档仍按游戏ID和哈希隔离。两个剑盾版本不能混房，也不会自动互相迁移存档。光明力量当前只开放单人，塞尔达单人过去篇与多人四人之剑须在游戏内选择正确模式。逐项说明见 ROM_COMPATIBILITY.md。

## 操作

| 键盘 | GBA |
| --- | --- |
| 方向键 | 十字键 |
| Z | A |
| X | B |
| Enter | Start |
| 左/右 Shift | Select |
| A | L |
| S | R |

网页工具栏可开关声音、全屏和导出存档。浏览器首次发声需要点击「开启声音」或房主开始按钮；其他玩家可自行打开声音。

## 自定义按键

展开游戏画面下方的「修改键盘按键」，点击要修改的动作，再按下新键。10 个 GBA 按键都能修改；Esc 取消，重复的键会自动互换，也可一键恢复默认。设置按游戏保存在当前浏览器当前网站，刷新后仍有效，各设备互不影响。默认卡比会兼容读取旧版按键。修改完成后点击游戏画面继续操作。键盘映射不改变触屏和标准手柄布局。

## 房间文字聊天

加入房间后，在房间面板下方输入消息，按 Enter 或点击发送。支持中文和 emoji，每条最多 300 个字符，每人每 5 秒最多 5 条。只有同房间的成员能收到，等待和游戏过程中都可聊天。新加入者可查看最近 50 条历史，房间内重新开机保留历史；房间无人或服务关闭时历史清空。

输入聊天消息、中文输入法组词或修改按键时，键盘不会操作游戏，并会释放此前按住的游戏键；游戏本身继续运行。

## 存档

- 每位玩家每 300 帧自动保存自己的电池存档至浏览器 localStorage，同时更新房间服务中的副本。
- 存档按「游戏 ID + ROM SHA-256 + 昵称 + 网站来源」区分。相同 ROM 在不同游戏 ID 下也独立存储；默认卡比会保留兼容迁移旧存档。换浏览器、设备、昵称、访问地址或清除浏览器数据会改变存档位置。
- 退出前可点击「导出存档」备份 .sav。导入支持常见 GBA 电池存档大小，必须在游戏停止时进行，下次开机生效。
- 导出的是游戏卡带电池存档，不是即时存档。原始 .gba 文件不会被改写。
- 房间和服务端存档副本只保存在内存；关闭服务器会清空房间，浏览器中已自动保存的存档仍在。

## 局域网连接

- 所有设备连接同一可互访的网络。访客 Wi-Fi 的「客户端隔离」会阻止互访。
- 其他设备不能使用 127.0.0.1，也不要使用 172.x 的 WSL/Hyper-V 虚拟网卡地址。选择主机 Wi-Fi/WLAN 的实际地址。
- 若本机可打开、其他设备打不开，请检查 Windows 防火墙是否允许此目录 runtime/node.exe 的 TCP 8765 入站连接（专用网络）。项目不会自动修改防火墙。
- 若端口由本项目服务占用，启动器会复用现有服务；若被其他程序占用，则依次尝试后续空闲端口，不会结束其他程序。以启动输出中的实际网址为准。也可在终端设置 PORT 指定起始端口。
- 默认双击启动为 LAN 模式。公网部署请使用同源 HTTPS/WSS 和访问口令，参见 DEPLOYMENT.md，不要直接将本地 8765 映射到公网。


## ROM 位置与公网登录

用户提供的 ROM 已完整移动至 data/roms/kirby-amazing-mirror-cn.gba，内容未改写；浏览器仍从 /game.gba 读取。默认游戏目录映射到此位置；多游戏用 GAME_CATALOG_PATH 与 ROM_DIRECTORY 配置。正式入口的 ROM_PATH 仅保留单 ROM 兼容模式，不能与显式 GAME_CATALOG_PATH 同时配置。

公网模式打开网址后先输入服主提供的站点口令。口令不会存入 localStorage，登录后由 HttpOnly Cookie 维持 12 小时会话。点击「退出访问」会关闭此浏览器会话下所有连接，相关正在运行的房间会停止。公网仍使用相同的房间、按键和聊天界面。
